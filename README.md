# reggie-portfolio

Portfolio website for **Reginald Aaron Dobeng** — Frontend Developer & Emerging UI Designer.

- **Live / Custom Domain:** [https://reggiee.tech](https://reggiee.tech)
- **Stack:** Semantic HTML5, Custom CSS3, Vanilla ES6+ JavaScript, Anime.js v4, Vite (static multi-page build)
- **Pages:** `index.html` (Main Portfolio), `scaleup-pos.html` (ScaleUp POS Case Study), `resume.html` (Print-ready Resume)

## Development & Build

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # Static MPA output to dist/
npm run preview
```
