BLOCK A

The Challenge

Retail and bakery operations frequently face unstable internet connectivity. Standard cloud-dependent POS systems freeze during network drops, halting customer checkouts and delaying daily sales reconciliation.

RETAIL + BAKERY  /  NETWORK RESILIENCE

BLOCK B

Offline-First Frontend Architecture

Engineered local browser persistence using IndexedDB via Dexie.js and LocalStorage. Cashiers can ring up orders, apply discounts, and manage cart state at zero latency while offline, automatically queuing transactions for background sync once connectivity returns.

INDEXEDDB  /  DEXIE.JS  /  LOCALSTORAGE

BLOCK C

UI Design & Django Template Integration

Designed a high-contrast, touch-friendly interface built entirely with semantic HTML5, custom CSS3 variables, and Vanilla JavaScript—eliminating heavy framework overhead—and integrated modular views cleanly into Django templates.

SEMANTIC HTML  /  CSS VARIABLES  /  DJANGO TEMPLATES
